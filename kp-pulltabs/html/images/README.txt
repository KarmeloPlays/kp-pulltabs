PUT YOUR PULL TAB IMAGES HERE

Add your images to this folder and reference them in config.lua.

Examples:
    html/images/lucky7.png
    html/images/bigwins.png
    html/images/carshow.png
    html/images/example.png

Then set:
    image = "images/example.png"

The image is used as the cover that the player physically pulls across each line.

Recommended image:
- PNG/JPG/WEBP
- Around 1000x120 pixels for a full pull strip
- You can use a different image for every pull tab.
